## Overview

The GitHub User App was built as a course project to apply modern Android development practices while integrating GitHub's REST API.

## Key Features

- **API Integration**: Consumed GitHub API with Retrofit for user search and details.
- **Local Storage**: Implemented Room Database for offline data persistence.
- **User Preferences**: Managed settings with SharedPreferences.
- **Best Practices**: Applied Clean Architecture, MVVM, Kotlin Flow, and modularization.

## Technologies Used

- Kotlin, Android SDK
- Retrofit, Room, SharedPreferences
- MVVM, Clean Architecture, Kotlin Flow
- Koin (Dependency Injection)
- CI/CD with CodeMagic

## Outcome

This project strengthened my Android development fundamentals, resulting in a production-ready app architecture with automated build and deployment pipelines.
