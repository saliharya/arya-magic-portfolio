## Overview

As part of the Bangkit Academy 2023–2024 cohort, I developed **CafeAlyzer**, a mobile app aimed at empowering small cafes with AI-driven competitor analysis and recommendations.

## Key Features

- **Competitor Analysis**: Compared nearby cafes based on multiple data points.
- **Sentiment Analysis**: Integrated ML models to analyze customer feedback.
- **Collaboration**: Worked with backend and ML engineers to ensure smooth integration.
- **UI & UX**: Delivered a clean Android app using modern architecture.

## Technologies Used

- Kotlin, Android SDK
- Retrofit, Room
- MVVM, Clean Architecture
- TensorFlow Lite (sentiment analysis)

## Outcome

The app showcased how AI can empower small businesses by providing actionable insights. It was delivered on time as a capstone project and received positive feedback from mentors and stakeholders.
