## Overview

E-Health Assistance is the patient-facing companion to Telehealth Indonesia's
monitoring platform. While ATM Sehat focuses on *ingesting* raw medical-device
readings, E-Health Assistance turns that data into an actionable dashboard —
synchronizing health records across devices and presenting them through charts,
trends, and history logs so doctors and patients can track progress over time.

## Key Features

- **Data Synchronization**: Kept patient health records consistent across devices and the backend.
- **Health Visualization**: Built interactive charts and trend views for metrics like glucose, ketone, and spirometry results.
- **History Logs**: Surfaced a chronological record of past readings to support diagnosis and follow-up.
- **Patient & Doctor Dashboards**: Tailored views that made the same data useful for both clinical and patient audiences.

## Technologies Used

- Kotlin, Android SDK
- MPAndroidChart for data visualization
- Retrofit for API integration
- MVVM, Clean Architecture

## Outcome

The dashboard gave doctors and patients a clear, longitudinal view of health
metrics — turning isolated test results into trends that informed better
remote-care decisions.
