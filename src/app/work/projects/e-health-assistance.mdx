## Overview

ATM Sehat is a telehealth application developed for **Telehealth Indonesia** to integrate manual medical test data into a digital health monitoring platform. This enables remote diagnostics and expands access to healthcare.

## Key Features

- **API Integration**: Added support for ketone, spirometer, and hematocrit data.  
- **Improved Diagnostics**: Enhanced the platform’s ability to provide comprehensive health insights.  
- **Collaboration**: Worked with medical professionals to validate data integration.

## Technologies Used

- Kotlin, Android SDK  
- Retrofit for API integration  
- MVVM, Clean Architecture  

## Outcome

The project improved diagnostic capabilities for remote users, providing doctors and patients with richer datasets for informed healthcare decisions.
