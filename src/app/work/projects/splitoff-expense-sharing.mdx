## Overview

SplitOff is a Flutter app designed for easy expense sharing among groups. It supports voucher systems, promo validation, and ensures smooth user experiences across Android and iOS.

## Key Features

- **Figma to Flutter**: Built reusable UI components based on design handoffs.
- **Bloc State Management**: Ensured predictable and scalable app flow.
- **Voucher Feature**: Integrated promo logic via backend APIs.
- **Cross-platform Support**: Optimized for Android & iOS.

## Technologies Used

- Flutter, Dart
- Bloc (Cubit) for state management
- RESTful API integration

## Outcome

Successfully deployed on Google Play Store, the app helps users split bills and manage group expenses efficiently.
