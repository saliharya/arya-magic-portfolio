## Overview

At **GetGoing** I worked across web and mobile as a **React & React Native developer**,
shipping three products: a **React web admin dashboard** and two **React Native**
apps — the **GetGoing** customer app and the **GetPartner** app. This role complements
my native Android focus with hands-on cross-platform and web experience.

## What I Built

- **Web Admin Dashboard (React)**: Built responsive, reusable UI from Figma handoffs
  for the internal/admin dashboard used to manage the platform.
- **GetGoing App (React Native)**: Developed and maintained features for the
  customer-facing mobile app.
- **GetPartner App (React Native)**: Built features for the partner-facing mobile app
  that complements the customer experience.
- **Serverless Backend**: Designed and deployed backend features using **Cloud
  Functions** integrated with **Firestore**.
- **Stability & Maintainability**: Resolved bugs to improve app stability and
  refactored code toward modern best practices for better readability and scalability.

## Technologies Used

- React (web), React Native (mobile)
- TypeScript, JavaScript
- Firebase (Cloud Functions, Firestore)
- Figma-driven component development

## Outcome

Delivering across a web dashboard and two React Native apps gave me production
experience spanning web and cross-platform mobile — a useful complement to my primary
Kotlin/Android work.
