## Overview

Feggyfy is an Android app built to assist farmers in early detection of crop diseases. By integrating AI-powered image recognition with TensorFlow Lite, the app helps reduce agricultural losses and improves productivity.

## Key Features

- **Jetpack Compose & CameraX**: Developed modern UI and integrated real-time image capture.
- **AI-powered Detection**: Implemented MobileNetV2 CNN with >70% accuracy.
- **Transfer Learning**: Built a custom dataset and applied transfer learning for model optimization.
- **User Validation**: Verified predictions with local farming experts (100% accuracy on 20 test images).

## Technologies Used

- Kotlin, Jetpack Compose, Clean Architecture, MVVM
- TensorFlow Lite, CameraX
- Firebase for backend integration

## Outcome

The app is now used in Kenteng, Boyolali, by farmers for daily disease detection, reducing diagnostic delays and supporting sustainable farming practices.
