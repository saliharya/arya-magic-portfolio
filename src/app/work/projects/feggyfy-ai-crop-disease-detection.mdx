## Overview

Feggyfy is an Android app built to assist farmers in early detection of crop diseases. By integrating AI-powered image recognition with TensorFlow Lite, the app helps reduce agricultural losses and improves productivity.

## Key Features

- **Real-time Detection**: Built with TensorFlow Lite integrated with MediaPipe on CameraX for seamless on-device analysis.
- **AI-powered Detection**: Implemented a MobileNetV2 CNN with transfer learning, reaching >70% accuracy.
- **Treatment Recommendations**: Provided actionable guidance on managing detected diseases to support farmers.
- **Scan History**: Stored past scan results in Firebase for tracking over time.
- **User Validation**: Verified predictions with local farming experts (100% accuracy on 20 test images).

## Technologies Used

- Kotlin, Jetpack Compose, Clean Architecture, MVVM
- TensorFlow Lite, MediaPipe, CameraX
- Firebase for scan-history storage and backend integration

## Outcome

The app is now used in Kenteng, Boyolali, by farmers for daily disease detection, reducing diagnostic delays and supporting sustainable farming practices.
