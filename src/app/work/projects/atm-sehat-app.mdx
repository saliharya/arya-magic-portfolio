## Overview

ATM Sehat is a telehealth application developed for **Telehealth Indonesia** that brings manual and device-based medical test data into a digital health platform. Its focus is the *ingestion layer* — capturing readings from medical devices and syncing them to the backend so they can power remote diagnostics. (The patient-facing visualization of this data lives in the companion E-Health Assistance dashboard.)

## Key Features

- **API Integration**: Added support for ketone, spirometer, and hematocrit data.  
- **Improved Diagnostics**: Enhanced the platform’s ability to provide comprehensive health insights.  
- **Collaboration**: Worked with medical professionals to validate data integration.

## Technologies Used

- Kotlin, Android SDK  
- Retrofit for API integration  
- MVVM, Clean Architecture  

## Outcome

The project improved diagnostic capabilities for remote users, providing doctors and patients with richer datasets for informed healthcare decisions.
