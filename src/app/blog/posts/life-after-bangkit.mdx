## A Learning Journey That Changed My Perspective

2023 was a turning point in my career as a developer.  
I had the privilege of joining **Bangkit Academy**, an independent study program initiated by **Google, GoTo, and Traveloka**.  

I chose the **Android Development Learning Path**, a track designed to guide participants from the very basics of Android development all the way to **expert-level skills**.  

This program not only sharpened my technical expertise but also shaped my mindset as a **professional software engineer**: writing clean code, building scalable applications, and collaborating effectively in a team with industry-standard practices.

---

## Courses I Completed

### Belajar Dasar Git dengan GitHub (*Basic Git with GitHub*) – *August 13, 2023*  
[Certificate](https://www.dicoding.com/certificates/1OP808JRQXQK)  
My journey started with mastering **Git and GitHub** — the foundation of modern software collaboration.  
I learned repository management, branching, merging, resolving conflicts, and handling pull requests.  
More importantly, I understood how to leverage GitHub as a **professional portfolio platform**.  

---

### Belajar Membuat Aplikasi Android untuk Pemula (*Android Apps for Beginners*) – *September 3, 2023*  
[Certificate](https://www.dicoding.com/certificates/EYX4Y14YWZDL)  
This was my introduction to **Android Studio** and my first attempt at building a real application.  
I explored **Activity lifecycles, Intents, Views & ViewGroups**, and learned how to use **RecyclerView** with libraries like Glide.  
The final project was a simple app displaying a list of content with a detail page — my very first Android app.  

---

### Belajar Prinsip Pemrograman SOLID (*SOLID Principles in Programming*) – *September 3, 2023*  
[Certificate](https://www.dicoding.com/certificates/81P27QELYZOY)  
Here, I dove deeper into **Object-Oriented Programming (OOP)** and mastered the **SOLID principles**.  
This course taught me why clean, structured, and maintainable code matters in real-world projects.  
Concepts like *Single Responsibility* and *Dependency Inversion* became essential tools in my developer toolkit.  

---

### Belajar Fundamental Aplikasi Android (*Fundamental Android Development*) – *October 4, 2023*  
[Certificate](https://www.dicoding.com/certificates/2VX36KJNVXYQ)  
At this stage, I moved on to **fundamental Android skills**:  
- Fragments & Navigation (Drawer, Bottom Navigation, TabLayout).  
- Networking with APIs, JSON parsing, and threading.  
- Architecture Components (ViewModel, LiveData).  
- Data persistence (File, DataStore, Room).  
- Testing (Unit & Instrumentation).  

The capstone project was an application that consumed data from a **Web API** and stored user favorites in a local database.  

---

### Belajar Pengembangan Aplikasi Android Intermediate (*Intermediate Android Development*) – *November 8, 2023*  
[Certificate](https://www.dicoding.com/certificates/JMZV171VJXN9)  
This course pushed me toward more advanced topics:  
- Advanced UI (Custom Views, Widgets, WebView).  
- Animation (Property Animation, Motion Layout).  
- Localization & Accessibility.  
- Services, Media management, and Google Maps with Geofencing.  
- Firebase (Authentication, Realtime Database, Cloud Messaging).  

The final project was a **Story App** — a social-style app for sharing photos, complete with paging and modern architecture.  

---

### Belajar Membuat Aplikasi Android dengan Jetpack Compose (*Android Apps with Jetpack Compose*) – *November 22, 2023*  
[Certificate](https://www.dicoding.com/certificates/07Z68O04MXQR)  
Next, I embraced **Jetpack Compose**, Android’s modern declarative UI toolkit.  
I learned about **Composable functions, State management, Lazy Lists, Navigation, and UI Testing** in Compose.  
The final project was a free-themed Android application built fully with Jetpack Compose.  

---

### Menjadi Android Developer Expert (*Becoming an Android Developer Expert*) – *March 3, 2024*  
[Certificate](https://www.dicoding.com/certificates/81P2VWVYOPOY)  
The peak of my journey was the **Android Developer Expert** course, where I learned industry-grade practices:  
- **Clean Architecture** for scalable apps.  
- **Reactive Programming** with RxJava & Kotlin Coroutines.  
- **Dependency Injection** with Dagger & Koin.  
- **Modularization** for large-scale projects.  
- **CI/CD pipelines, Performance optimization, and Security best practices**.  

The final project was an enterprise-ready Android app, applying all advanced components and architectural patterns.  

## Reflection

Through this journey at **Bangkit Academy 2023**, I gained more than technical skills.  
I developed the ability to think like an **engineer**: designing for scalability, writing clean and testable code, and adopting best practices used in the global tech industry.  

From my very first Android app to building an **expert-level project with Clean Architecture and CI/CD**, this program shaped me into a more confident, capable, and industry-ready **Android Developer**.
